# BIT502 Assessment 1 - Bonus GUI Interface

## File: `BIT502_AS1_Stefan_Gislason_GUI.py`

This is an **optional bonus GUI version** created as additional work beyond the assignment requirements.

## Description

This is a graphical user interface (GUI) implementation of the Library Management System using tkinter. It provides the same functionality as the CLI version but with a modern kiosk-style interface designed to look like a self-service kiosk.

## Features

All features from the CLI version, plus:
- Visual kiosk-style interface
- Cart system to accumulate selections
- Checkout with final total calculation
- Receipt-style display showing current selections
- Touch-friendly large buttons
- Navigation bar for easy movement between sections

## How to Run

```bash
python BIT502_AS1_Stefan_Gislason_GUI.py
```

## Requirements

- Python 3.x
- tkinter (usually included with Python)

## Note

This GUI version was created as additional practice and to demonstrate understanding of GUI programming concepts. The main assignment submission is the CLI version located in the `Main_Assessment` folder.
